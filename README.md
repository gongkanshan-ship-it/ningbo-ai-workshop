# 律所合伙人 AI 赋能专项研修班（第一期·领航班）

蓝白宁波版网站，研修手册版（v12）。纯静态 HTML / CSS / JavaScript。

## 手机与电脑适配

- 同一网址按屏幕宽度自动排版，电脑保留横向导航与双栏插画；手机使用可展开导航与单栏内容。
- 两天课表切换等高；课程材料、配置和积分结果弹窗支持窄屏阅读。
- 手机积分榜在表格内部横向滚动，小组列固定，全部分项保留。
- `dist/responsive.css` 负责公共布局；v9 的指引、资料卡与活动内容样式在其后加载。
- 本版检查课前指引切换、两天课表等高、统一材料弹窗、导航和小组任务排版；未进行微信真机测试。

## 内容状态

- 页面顺序为活动首页、课前指引、两天课表、五课介绍、小组与任务、积分中心、现场帮助。
- 课前指引采用最新学习指南的“学员须知”和“课前指引”两页，展示电脑与网络、WorkBuddy、企查查 MCP 和班务/技术联系方式。
- 课前指引使用深蓝导读栏与三步排版；Mac / Windows 系统要求可切换，主标签和系统标签支持键盘操作。准备事项仅展示，不记录勾选进度。
- “课前准备／学员须知”按当前内容自然撑高，联系人紧随其后；仅 Mac / Windows 的小面板保持等高。
- 活动日期为 2026 年 11 月 7—8 日；课表按最新指南展示上下午安排，具体起止时间、讲师和地点待公布。
- 每组 10 人、自选组长、配 1 名观察员、提交 1 个 Skill；真实分组名单仍待公布。
- 全部课程材料合并为一个 ZIP 下载入口，当前标注“待发布”并禁用下载。没有提供分课材料下载或临时替代包。
- 积分数据为清楚标注的虚拟演示结果，尚未接入真实成绩或后台。网站只展示各组分项、总分与排序；逐笔登记、修改历史和依据由组织者在飞书多维表格中管理，不随网站发布。

## 本地预览

```sh
python3 -m http.server 8770 --bind 127.0.0.1 --directory dist
```

首页入口为 http://127.0.0.1:8770/ 。

## 维护和发布

Vercel 使用 Other / 无框架预设，输出目录 `dist`，无需依赖安装与构建命令；配置见 `vercel.json`。

- `dist/index.html`：页面结构。
- `dist/styles.css`、`schedule.css`、`roster.css`、`scoring.css`、`responsive.css`：基础样式。
- `dist/guide.js`、`guide.css`：第二屏课前指引及学员须知。
- `dist/resources.js`、`resources-v9.css`：统一资料包入口及五课软件配置。
- `dist/workshop-v9.css`：本期活动信息和小组任务样式。
- `dist/app.js`：课程内容和导航；其他同名 JS 文件处理各模块交互。
- `dist/data/schedule.js`：两天拟定课表。五课名称、内容、顺序来自 10.17 修订 Word，分日及上下午时段沿用学习指南，具体钟点待公布。作为普通脚本加载，可直接打开本地 HTML 查看课表；不另维护 JSON 副本。更新时同步递增 `index.html` 中该脚本的版本参数。
- `dist/data/roster.json`：名册（当前待公布）。
- `dist/data/score-results.json`：仅含各组当前分项结果，总分由页面计算。发布前先在飞书中核对，再更新这个结果文件；当前尚未接入飞书自动同步。不要将原始记录、修改原因、报送人或依据放入公开目录。
- `dist/downloads/`：旧版准备说明留档，当前页面不再链接。正式全部课程材料包尚未发布；就绪后更新 `resources.js` 的统一入口。
- `dist/assets/`：当前实际使用的三张宁波插画。

发布内容仅在 `dist/` 中。不包含筹备源文档或历次预览截图。
